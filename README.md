# Lanework Support

This is where to report a problem with Lanework, the native Mac kanban app whose boards are plain folders of Markdown, or to ask for something it doesn't do yet. The app's code isn't here: this repository exists for its issue tracker.

## Before you file

- Check the [Support page](https://laneworkapp.com/support/) for answers to common questions.
- Search the [existing issues](https://github.com/laneworkapp/lanework-support/issues?q=is%3Aissue). Add a comment or a 👍 to an existing one rather than opening a duplicate.

## Filing an issue

[Open an issue](https://github.com/laneworkapp/lanework-support/issues/new/choose) and pick the form that fits:

- **Bug report**: something that doesn't work the way it should.
- **Feature request**: something you'd like Lanework to do.
- **Question**: something the Support page doesn't answer.

The bug form asks for your macOS version, your Lanework version and build (shown in Lanework's About window), and what happened. Because a board is just files, the most useful attachment is often a small board that shows the problem. Zip a copy of the `.lanework` folder with only the cards needed to reproduce it.

## Issues are public

Everything posted here, attachments included, can be read by anyone. Before you attach a board, a screenshot or a log, remove anything private: card titles, notes, names, file paths.

If you need to share something private, email [support@laneworkapp.com](mailto:support@laneworkapp.com) instead. Do the same for security issues: please don't report them here.

## Beta testers

If you're testing Lanework through TestFlight, you can also send feedback from the TestFlight app, which reaches me privately with a screenshot and device details. Issues here are better for anything you'd like others to see or follow.

## What to expect

Lanework is made by one person, Rouslan Zenetl. I read every issue, but I can't promise a reply time or that every request will be built. When an issue is fixed, it's closed with a note saying which release the fix is in.
